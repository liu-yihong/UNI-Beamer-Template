# Optional fonts

Nothing is required here. Emoji are rendered with **Noto Color Emoji**, which ships with
TeX Live, MiKTeX and Overleaf (Windows' **Segoe UI Emoji** is used as a fallback).

If neither is available, drop a color-emoji font such as `joypixels-android.ttf` into this
folder and the template will pick it up. Font files here are git-ignored because many
font licenses do not allow redistribution.
